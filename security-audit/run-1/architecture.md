# Architecture summary (core/backend, quick profile)

**Product.** Nile: produce/commodity marketplace. Go microservices (api GraphQL gateway, administrator, ledger, trader, librarian, harvester, postman, nilocloud ops/webhook service, billing) in backend/go; Firebase Cloud Functions (Node, backend/functions/firebase); a Raspberry Pi label-print relay (backend/relay/relay.py); Gerrit CI/CD automation (backend/go/gerrit) driven by the Horus Slack bot. Scope: backend/ only; client/ is out of scope.

**Principals.** Unauthenticated caller (Authorization: `unauthenticated`; may call Signup/ValidateCurrentToken), Firebase end users (Buyer/Seller/Admin party types, 25 roles from custom claims, tenant = admin_profile_id claim checked against X-Platform), shared robot token (hardcoded, auth/auth.go:30), PotatoesSA token (hardcoded, exportData only), Cloud Scheduler OIDC SA, internal services (gRPC), Slack users (Horus), Gerrit, print relay Pi.

**Stack / deployment.** Go 1.27, gqlgen, gRPC/protobuf, MySQL/AlloyDB/Redis, Pub/Sub, Firestore. Cloud Run services deployed with --allow-unauthenticated per cloudbuild.yaml (recon claim; ingress/IAM not in source). Deploys via Gerrit agent VM + Cloud Build + Cloud Functions gen2 (gerrit-webhook public, allUsers). Offline test: `go test ./...`; no target code will be executed in this run (no complete sandbox guarantee), so runtime-dependent claims become needs_validation.

**Entry surfaces and key paths.** api: /graphql (AuthOperation), /docs/pdf (AuthHTTP), Twilio webhooks (HMAC). nilocloud: /v1/webhooks/{sentry,grafana} (query-string robot token), /v1/events/unblock, /v1/subscriptions/{nilo,cloudbuild} (auth middleware appears to be a no-op), /v1/mache, /v1/gerrit/checks* (no auth), Slack routes (signature only; Horus can deploy/migrate production). gRPC: thoth/handlers.go trusts plaintext `user-firebase-id` metadata, robot IDs accepted without credential. Gerrit webhook function: no HMAC in code despite terraform comment. Firebase generatePdf: unauthenticated, loads caller URL in Puppeteer and appends robot token. signupBlocking uses substring email check. harvester potatoesSA zip extraction (possible zip-slip). fortknox AES-CTR without MAC with TODO review. seshat OData $filter string interpolation. relay: raw ZPL from Pub/Sub to printer; printKey becomes Firestore doc id.

**Trust boundaries / strongest visible control.** Firebase ID token verification + claims + checkPlatform (api); Twilio/Slack signature verification; scheduler OIDC audience/email check; per-resource Authorized helpers in api/internal/graph/auth_checks.go. No token revocation check; no rate limits or request size limits on HTTP servers.

**Starting paths.** backend/go/auth, backend/go/thoth, backend/go/nilocloud/internal, backend/go/gerrit, backend/functions/firebase/functions/src, backend/go/api, backend/go/harvester, backend/go/seshat, backend/go/fortknox, backend/relay.

**Prior coverage.** No prior run or ledger exists; none carried. Same-source exclusions: none.

**Companion selection.** WEB-PROTOCOL-AND-AUTH (API-key, federated identity: shared tokens, signup), PROTOCOLS-RPC-AND-MESSAGING (gRPC identity, relay/Pub/Sub), SUPPLY-CHAIN-AND-RELEASE (Gerrit/CI), DATA-ISOLATION-AND-LIFECYCLE (tenant scoping), RESOURCE-EXHAUSTION-AND-AVAILABILITY (unbounded HTTP). Excluded: MEMORY-SAFETY-AND-BINARY (Go/Python/TS only), DESKTOP-MOBILE-AND-LOCAL-IPC and CLIENT-SIDE (client/ out of scope), AI-AND-LLM (no model/tool boundary visible), CLOUD-AND-DEPLOYMENT as primary (deployment facts are not in source; used only for needs_validation framing).
