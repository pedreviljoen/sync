# Architecture summary (core/client, quick profile)

**Product.** Nile market: produce marketplace/ERP. Clients: `client/market` (React 19/Vite/urql/Firebase web app, white-label nile/freshmark/villa variants, also hosted inside the iOS WKWebView and in Android TWA wrappers), `client/ios` (SwiftUI WKWebView wrapper of market, 4 schemes), `client/ios-native` (native SwiftUI "Nile Farmer" packhouse/dispatch app, offline queue + sync, Apollo GraphQL, Firebase Auth/Google/Apple sign-in), `client/android` and `client/freshmark-android` (Bubblewrap TWA wrappers, config only), `client/android-native/nile-farmer` (Compose skeleton, no networking), `client/website` (Astro static marketing site), `client/freshtrader-software` (static page). Scope: client/ only; backend findings from run-1 are used only to judge what the server enforces.

**Principals.** Anonymous web visitor; authenticated buyer/seller/admin (Firebase ID token with custom claims); holder of the shared "robot token"; staff (@nile.ag, can switch environment in ios-native); other tenants' users reached via data rendered in the UI.

**Trust model.** Clients authenticate with `Authorization: Bearer <Firebase ID token>` and client-chosen `X-Platform`; the backend (run-1) is the real authorization boundary. Client-side role gating and "robot mode" are UI only. Firestore/Storage security rules are not in the repo.

**Entry surfaces and key paths (recon claims, unverified).**
- market: `?robotToken=` in URL makes `getToken` return the robot token and gives the UI an Admin-shaped user (`src/services/auth.ts:33-52`, `src/hooks/useRobotToken.ts`, `src/interfaces/user.ts:56-69`); `localStorage['appToken']` -> `signInWithCustomToken` (`src/components/AuthCheck.tsx`); `/form?type&ids&profileID` params (`src/screens/FormScreenLauncher.tsx`); `dangerouslySetInnerHTML={form.description}` unsanitised (`src/components/Form.tsx:122`); server-supplied URLs used as `href`/`window.open`/`location.href` (`ActionList.tsx`, `useHandleLink.ts`, `Explore/*`); `isNileUrl` substring check; PDF URL builders (`utils/get-pdf-url.ts` name unencoded, forwards `window.location.href`; `utils/method-download-pdf.ts`); Sentry receives `window.location.href`; Firestore chat paths from client; Storage REST upload with client Content-Type; Debug screen dumps storage; no CSP/HSTS, inconsistent headers (firebase.json vs Dockerfile; nginx runs as root).
- ios (wrapper): WKWebView allow-by-default navigation, no host allowlist; `startDownload` message handler fetches page-supplied URL, unsanitised filename used in temp path (`NileWebView.swift:428-452, 570-705`); universal-link handler loads any URL (`NileApp.swift:257-286`); `deviceToken` interpolated into evaluateJavaScript; FCM token printed; Sentry breadcrumbs with URLs; CI script may echo `SENTRY_AUTH_TOKEN`.
- ios-native: Keychain token (default accessibility, not cleared on environment switch, `EnvironmentManager.swift:341-345`); client-chosen X-Platform from UserDefaults/JWT; staff gate `isNileStaff` client-side; offline queue/caches/images with no file protection and backed up; `print` logging of email/IDs; Sentry `sendDefaultPii=true` + 100% error session replay; image upload to Firebase Storage.
- android/TWA: `fingerprints: []`, no committed manifest; freshmark fullScopeUrl is the whole origin; keystore/Play key held in private repo; native app has allowBackup=true, minify off.
- website: Slack incoming-webhook URL hardcoded in `package.json` script run as postdeploy; `define:vars` inlines entire `import.meta.env`; `.yarnrc.yml` enableScripts/no age gate.
- Cross-cutting: robot token literal committed in `client/market/graphql.config.ts`, `client/ios/README.md:10`, `client/ios-native/.../apollo-ios-gen-schema.sh` (same scheme as run-1 `auth/hardcoded-shared-robot-token`); two different prod GraphQL hosts; Firebase API keys/Sentry DSNs committed (public by design).

**Starting paths.** client/market/src (services, components, screens, utils, hooks), client/market/{firebase.json,Dockerfile,index.html,graphql.config.ts}, client/ios/Nile/Nile, client/ios-native/Farmer App/Nile Farmer, client/android*, client/website, client/freshtrader-software.

**Prior coverage.** None for client/ (run-1 covered backend/ only). No same-source exclusions.

**Companion selection.** CLIENT-SIDE (DOM sinks, browser storage, navigation, cross-origin/network), DESKTOP-MOBILE-AND-LOCAL-IPC (webview bridge, deep links, application state), WEB-PROTOCOL-AND-AUTH (session/token, API-key), SUPPLY-CHAIN-AND-RELEASE (CI, build inputs). Excluded: MEMORY-SAFETY-AND-BINARY (no native memory-unsafe code in scope), AI-AND-LLM (no model boundary), RESOURCE-EXHAUSTION (little server-side surface in client/), DATA-ISOLATION/PROTOCOLS-RPC (server-side; covered in run-1).
